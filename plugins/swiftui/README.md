# SwiftUI Production Intelligence for Codex

This Codex plugin grounds SwiftUI work in real usage from 1,857 shipping macOS apps.

Use the explicit workflows with `$swiftui`, `$swiftui-review`, `$swiftui-audit`, and `$swiftui-settings`. The original domain skills remain available for automatic selection. Six bundled, read-only MCP tools expose lookup, search, examples, source retrieval, recipes, and deprecation checks.

The plugin targets local macOS Codex CLI, desktop, and IDE environments. Its native `swiftui-ctx` binary downloads on first use or builds from the bundled Swift package when Xcode is available. The Git marketplace contains the complete plugin, so installation and runtime queries do not require npm.
